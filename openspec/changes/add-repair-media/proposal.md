# Proposal

## Why

文字难以交代一些现场现象。报修人需要在提交工单时附上照片或短视频，管理员和实际负责的维修人员可直接核对。

## What Changes

- 人工建单支持可选多图和短视频，提交前可预览或移除。已有纯文字建单继续兼容。
- 工单详情提供授权图片预览和视频播放。
- 服务端校验媒体、去除原始元数据、限制容量和时长，并将附件与工单一同保存。
- 本轮采用现有工单布局，仅增加附件区。整页布局另行迭代。

## Capabilities

### New Capabilities

- `repair-media`：报修现场附件的输入、验证、存储和授权查看。

### Modified Capabilities

无已归档主规约。此变更扩展未归档 MVP 的人工报修及工单详情。

## Impact

React、工单 API、MySQL、上传代理和容器镜像。业务状态、角色归属及 AI/MCP 的只读边界沿用。

普通表单与助手草稿均支持本人附图或视频，助手的能力说明、派单追问与筛选使用现行故障目录。
