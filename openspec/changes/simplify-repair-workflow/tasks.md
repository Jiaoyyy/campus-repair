# Tasks

- [ ] 1.1 用常规照明、间歇性故障、现场无法验证和上门异常示例确定各结单路径的准入、超时及反馈期限、可见性。同步现有 MVP 和上门规约。

## 2. 减少结单与再派单交接

- [ ] 2.1 实现现场关闭、必须确认及有时限确认，记录结单依据和服务端截止时间，核对角色权限及待办计数。
- [ ] 2.2 实现可重试的到期任务与事务审计，验证截止边界、并发反馈、重复执行、失败恢复，以及不影响历史待确认工单。
- [ ] 2.3 实现本人未解决反馈和原维修人员继续处理的规则，验证账号停用、类别变更和越权。
- [ ] 2.4 对齐页面、只读 MCP、审计与统计，区分实际关闭依据及用户下一步。

## 3. 补齐上门与审核交接

- [ ] 3.1 补齐过期且未预约的时间窗更新路径，验证同一时间窗重试、更新后可预约、既有白跑与备件场景。
- [ ] 3.2 用实际审核及派单样例核对组合操作是否节省步骤。若启用，验证权限、人员变更、并发、回滚和分别记账。

## 4. 隔离验证与上线范围
