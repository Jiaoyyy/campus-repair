# Spec Delta

## Purpose

减少管理员连续工作的重复说明和冗余导航，把报修管理作为主要工作入口，将上门异常作为其中的一个视图；保留必要字段标签、真实错误、危险操作影响及未保存保护，让页面直接表达可做的工作。

## ADDED Requirements

### Requirement: 减少冗余说明
设置页 SHALL 移除重复说明基本信息、提示词权限、材料范围和只读工具的常驻提示，必要业务约束保留在文档与服务端。列表 SHALL 去除重复主要动作和终结状态的小字，保留状态及明确动作按钮；关键标签、错误、未保存状态和危险确认不能一并删除。

#### Scenario: 设置与列表
- **WHEN** 管理员查看助手设置和待审核工单
- **THEN** 直接看到分组字段，不出现审核反馈指出的四段说明；待审核状态旁不再重复显示“审核”小字，仍有审核按钮

### Requirement: 报修管理整合上门异常
管理员侧栏 SHALL 首先显示报修管理，不再并列显示上门异常；管理区域通过“工单列表 / 上门异常”内部入口切换。原上门路径、队列、详情直达和返回 SHALL 继续有效，当前所属导航明确。

#### Scenario: 旧路径与返回
- **WHEN** 管理员从旧上门异常路径进入详情，再返回或刷新
- **THEN** 属于报修管理导航、选中上门异常内部入口，保留原队列；维修人员工作台与报修人入口不受影响
