# Spec Delta

## Purpose

使报修平台能够从共同仓库按文档启动、持久化和部署到公网，并在后台索引、重启、依赖故障及备份恢复场景下保持业务可用，区分进程存活、依赖就绪与已完成交付。

## ADDED Requirements

### Requirement: 可复现启动与初始化
系统 SHALL 提供容器启动、环境配置、数据库迁移及幂等种子说明；种子至少覆盖三角色、同组织两个报修人和两个维修人员及另一组织隔离账号。重复启动不复制账号或覆盖用户工单，初始密码从本地配置读取，无共享默认凭据。

#### Scenario: 新环境启动
- **WHEN** 部署者按说明设置必需变量并启动容器
- **THEN** 服务可登录并完成业务，种子可用于同组织归属和跨组织权限测试

#### Scenario: 缺少必需配置
- **WHEN** 数据库密码或会话密钥等必需配置缺失
- **THEN** 启动明确失败并指出变量名，不泄露变量值

### Requirement: 持久化、后台恢复与健康状态
系统 SHALL 持久化账号、工单、会话、审计、原材料与索引任务；普通停止重建不能删除数据。后台处理中任务在进程中断后可恢复，不重复发布有效索引。提供存活与就绪检查：数据库不可用时就绪返回 503；模型故障不影响人工业务就绪，但能力状态明确不可用。

#### Scenario: 中断索引后重启
- **WHEN** 材料索引处理中停止并重启服务
- **THEN** 任务恢复或可重试，原材料和工单保留，不重复生成当前有效索引

### Requirement: 公网与密钥边界
交付 SHALL 提供实际 HTTPS 公网地址，浏览器只经统一入口访问，数据库、向量和内部 MCP 服务不直接公开。模型密钥仅给服务端，不进入前端包、仓库或错误响应；生产部署拒绝默认密码，关闭调试输出，限制上传和登录请求。

#### Scenario: 外部网络验收
- **WHEN** 验收者从非开发主机访问公网地址
- **THEN** 可登录并完成三角色主流程；本机 localhost 预览不能替代此证据

### Requirement: 备份恢复与回滚说明
交付 MUST 提供数据库和上传材料同一时点备份、恢复及版本回滚说明，并记录至少一次隔离环境恢复演练。操作不能把删除持久卷作为常规回滚；恢复后重建派生向量索引，验证工单记录与原材料一致。

#### Scenario: 恢复演练
- **WHEN** 使用备份在隔离环境恢复并重建索引
- **THEN** 工单、账号、处理历史与原文件可核对，记录恢复结果与限制
