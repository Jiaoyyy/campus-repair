# 页面布局与导航说明

更新日期：2026-10-30。适用于本轮前端优化；业务权限、工单状态规则及AI/MCP只读边界沿用原规约。

## 统一视觉规范

本轮使用ui-ux-pro-max辅助审查，项目规则见[设计规范](../design-system/campus-repair/MASTER.md)。保留绿色品牌，采用深绿导航和浅色工作区，统一标题图形、间距、圆角、边界与状态色；不加载外部字体。概览改为一个分段面板，当前队列同时有文字、底色和底部标记，待办条减少高度，让实际工单更早进入视线。

上门异常卡片先显示位置和故障，再分开显示问题与下一步责任，最后进入上门记录。助手欢迎区左对齐，示例与历史使用次要样式，发送使用主色；长消息和草稿在消息区内部滚动。知识、设置、原文侧栏和登录使用同一套颜色与控件。

手机菜单可用“关闭菜单”、遮罩和Escape退出；打开时焦点位于关闭按钮，Tab在菜单内循环，关闭后回到菜单入口。点击当前页也会关闭；选择其他页先关闭菜单，再执行原有未保存提醒。展开菜单后切回桌面宽度会自动关闭，并把焦点交给主要内容。

手机常用按钮和选择框采用44 CSS px点击高度，输入使用16px，控件焦点清楚可见。页面遵循减少动态效果偏好。这些是产品设计规则，实机、辅助技术和其他浏览器的完整验收仍需实际执行。

## 从待办开始

报修管理默认看“待我处理”；报修人首页保留全部报修并突出待补充、待确认入口。概览卡片可切换全部、待办、未结束、已结束，列表标题对应当前队列，不再重复占用一排标签。工单行显示审核、派单、接单等当前下一步。“定位待办列表”清除位置、类别、状态和分页限制，将视口与键盘焦点移至列表；已在待办时再次点击也会显示提示。

详情依次呈现当前位置、状态及负责方、故障与主要操作、上门安排、维修记录和时间线。报修人等详细信息可展开查看；手机压缩步骤条及重复信息。当前仍有主要操作时，取消、改派等低频动作在“其他操作”中；如果只剩次要操作，入口并入报修信息卡底部，不保留独立侧栏。点击后才展开原因或人员表单，仍须主动确认并通过服务端校验。

维修工作台先显示任务与操作入口，上门异常先显示异常队列；白跑统计和口径放在队列之后。没有符合条件的记录、读取失败及正在读取分别展示，不把失败当作零待办。

## 上门异常是看什么的

这个入口以前叫“上门协调”，实际用于管理员发现上门过程卡在哪里、知道下一步该跟进谁；按钮执行的是查看记录。

| 情况 | 入列原因 | 下一步负责的人及操作 |
| --- | --- | --- |
| 上门超时 | 超过约定结束时间，尚未记录到场 | 当前维修人员核实进展；已出发仍能补充真实到场，未出发则重新约定未来时间 |
| 需要重新约时间 | 此前记录到场无人，当前没有新预约 | 缺有效新时间时由报修人填写；已有有效新时间则由维修人员确认预约 |
| 等待备件 | 已记录缺少备件且尚未恢复 | 当前维修人员跟进备件，到位后填写说明恢复处理；已有再次上门要求的还需重新预约并到场 |

“查看上门记录”打开同一工单的上门区域，显示相同的原因、负责方与下一步；不再用“查看并协调”暗示有未实现的处置动作。管理员不能代填本人时间、代记维修人员出发/到场或直接改派处理中工单，页面没有自动通知。更新记录后，刷新可核对队列变化。超时是尚未记录到场，不等同于现场一定无人到达。

## 返回和继续工作

页面路径使用 `#/list`、`#/workbench`、`#/assistant`、`#/orders/工单ID`、`#/orders/工单ID/visit` 等格式，支持浏览器后退、前进和刷新。详情“返回”沿当前浏览器历史回到实际来源；直接打开详情且没有站内前序记录时，回到本角色主页。

同一次页面运行中，列表筛选、分页与页面滚动位置、工作台队列、助手对话及消息滚动区域会保留。工作台的队列和页码按用户保存在浏览器会话存储，详情刷新后返回也能恢复。助手仅保存当前用户选中会话的ID到浏览器会话存储，刷新后重新经鉴权接口读取记录；不把消息正文、凭据或草稿放入URL。完整刷新会重新读取页面，列表筛选不承诺跨刷新保存。

未保存的报修表单、派单/处理输入、上门编辑、助手草稿及配置在站内离开和浏览器后退时受保护。选择“继续编辑”保留输入及地址；确认放弃后离开。浏览器刷新或关闭时使用浏览器自身的未保存提醒。退出登录是独立操作，页面返回不会调用退出接口。

## 助手和共享控件

助手按可用视口排版，消息独立滚动；长工单卡片、草稿和历史不再把面板撑出屏幕。手机历史按需展开，发送/停止保留在输入区；较短屏幕中卡片需要在消息区滚动阅读。业务结果优先展示结构化卡片，重复的文字说明可展开。输入框与字数反馈均限制为2000字。

选择框使用统一样式和选中标记，支持方向键、Home/End、Enter、Escape、Tab及点击外部关闭；长选项换行并限制在视口内。保留必填与禁用表单语义。复选框、单选框、日期输入的尺寸、边框和焦点统一，日期编辑保留浏览器能力。

## 审核反馈精简（2026-10-30）

管理员侧栏以“报修管理”为首入口，内部“工单列表 / 上门异常”切换；旧`#/workbench`仍打开上门异常，详情返回原队列。维修人员工作台保留原入口。设置页去掉基本信息、提示词权限、绑定范围和工具范围的四段常驻说明；约束仍在服务端执行。列表删除状态旁重复“审核/派单”等小字及概览重复解释，保留真正的动作按钮、错误、未保存提示与危险操作确认。
