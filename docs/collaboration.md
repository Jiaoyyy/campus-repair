## 仓库与工作流程

共同仓库：https://github.com/Jiaoyyy/campus-repair 。公开仓库不表示任何人可以推送；组员须接受协作者邀请后获得写权限。

高慧莹的 GitHub 用户名待补，当前未发送邀请。确认用户名后由仓库管理员通过 Settings → Collaborators 添加，组员接受邀请。

1. 克隆共同仓库，每次开工先同步 main。
2. 从 main 建任务分支，记录对应 OpenSpec 任务编号。
3. 需求调整先改规约，再实现和运行相关验证。
4. 提交 PR，说明问题、改动及实际验证结果；由另一位成员检查权限和失败路径。
5. 审阅通过后合并，双方同步 main；不要 force-push 共同分支。

建议保留 docs/verification.md 和 docs/contributions.md：记录测试日期、场景、结果、证据位置及实际贡献，不能预填成功或虚构工作量。
