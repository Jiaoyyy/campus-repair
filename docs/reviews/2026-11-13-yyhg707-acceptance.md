## 4. 失败项详情

### CLOSE-03 / 知识引用（Issue #4）

- 实际结果：requester 在 18087 助手中询问“报修需要填写哪些信息？”、“维修时有哪些安全注意事项？”以及“不要自行拆电路或进行带电操作”，回答均显示“本轮回答未引用可核对资料”，页面没有可点击引用或原文入口。
- 预期结果：命中知识材料时展示可核对的资料引用；没有匹配时明确说明未找到资料。
- 报错/日志：无异常堆栈；页面明确返回未引用提示。
- 疑似原因：知识材料已显示 `vector_ready=true`，embedding 实测可用，但真实助手问答的检索/引用展示链路未产出 citation。
- 涉及文件：需维护者依据 Issue #4 追查；本轮没有修改业务代码。
- Issue：`#4 知识库回答缺少可核对资料的引用入口`

### 构建环境问题（不属于业务失败）

- 主机直接执行 `go test` 失败：`zsh: command not found: go`。
- 主机第一次执行前端 build 失败：`sh: tsc: command not found`。
- 按 README 使用 `golang:1.24-alpine` 容器后，`go test ./... && go vet ./...` 通过；前端执行 `npm ci && npm run build` 后通过。
- 判定：环境依赖问题已绕过，业务构建结果通过；不创建业务 Issue。
